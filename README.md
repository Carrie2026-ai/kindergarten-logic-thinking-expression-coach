# 幼教逻辑思考与表达训练助手

一个专门陪幼儿园教师训练 **逻辑思考与清晰表达** 的 AI Skill。

它不是替你把话改漂亮，也不是给你一份标准答案。

它做的事情更简单：

> **你先自己说，我帮你把脑子里的线理出来，然后你再自己说一次。**

## 为什么做这个 Skill

很多一线教师并不是没有经验、没有判断。

真正困难的是：

- 脑子里有很多东西，一说就散；
- 明明觉得不对，但说不清为什么；
- 举了很多例子，却没说清例子和观点的关系；
- 教研现场想到哪里说到哪里；
- 很容易用“大词”，但落不到事实；
- 遇到反方意见后，自己的观点就开始摇晃。

这个 Skill 就专门练这些。

## 它怎么训练

不会第一轮就给你 AI 范文。

流程通常是：

1. 你自由表达；
2. 帮你找核心观点；
3. 一次只指出 1—2 个关键问题；
4. 给一个很小的表达骨架；
5. 你自己重新说；
6. 再一起看哪里变清楚了；
7. 必要时才看示范。

## 五级训练

1. **一句话说清楚**
2. **观点 + 理由**
3. **观点 + 理由 + 证据**
4. **结构化表达**
5. **边界 + 反方**

## 可以练什么

- 幼教观点讨论；
- 教研发言；
- 课程点评；
- 园本交流；
- 公众号观点表达；
- 专业写作；
- 面对不同意见时的清晰表达。

## 自带幼教话题库

例如：

- 教师是不是越少介入儿童游戏越好？
- 儿童兴趣都值得生成课程吗？
- 常规好是不是代表班级管理好？
- 家长要求多识字，教师应该直接拒绝吗？
- AI 会不会让教师越来越不会写？

这些问题没有唯一标准答案。

训练重点始终是：

> **你的观点能不能站得住，也能不能说得清楚。**
